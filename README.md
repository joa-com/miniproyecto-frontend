# Mini Proyecto Frontend - Listado de Tareas

## Descripción

Este proyecto consiste en una aplicación web de lista de tareas desarrollada con HTML, CSS y JavaScript. Permite crear, administrar y almacenar tareas de forma persistente utilizando LocalStorage del navegador.

El objetivo del proyecto fue aplicar conceptos fundamentales de desarrollo frontend, manipulación del DOM, módulos de JavaScript y control de versiones mediante Git y GitHub.

---

## Funcionalidades

- Agregar nuevas tareas.
- Validar que la descripción no esté vacía.
- Marcar tareas como completadas.
- Eliminar tareas individuales.
- Filtrar tareas por:
  - Todas
  - Pendientes
  - Completadas
- Contador de tareas pendientes.
- Almacenamiento persistente mediante LocalStorage.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `index.html` utilizando la extensión Live Server.

## Uso

1. Escribir una tarea en el campo de texto.
2. Presionar **Agregar tarea** o la tecla **Enter**.
3. Marcar las tareas completadas mediante la casilla de verificación.
4. Eliminar tareas utilizando el botón **Eliminar**.
5. Utilizar los filtros para visualizar todas las tareas, únicamente las pendientes o solamente las completadas.

Las tareas permanecen guardadas automáticamente incluso después de cerrar o recargar el navegador.
